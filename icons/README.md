# Icons

Place your extension icons here:

- `icon16.png` - 16x16 pixels (toolbar)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Quick Icon Creation

You can create simple placeholder icons or use a design tool like:
- Figma
- Canva
- Adobe Illustrator
- Or use an online icon generator

For now, you can use any PNG images with the correct dimensions.

The icons should represent the Plotta brand - consider using:
- A sticky note symbol
- The Plotta logo
- Simple geometric shapes in your brand colors
